Detailed Description

Concrete state: the work node has finished successfully.

This is an end state and handle() does nothing. Completion is announced elsewhere: Escalated::handle() completes the parent project when its last child is done, and WorkNode::advanceState() tells the mediator, which releases work that waits on this node as a prerequisite.

Design pattern
State (ConcreteState); the context is WorkNode.
