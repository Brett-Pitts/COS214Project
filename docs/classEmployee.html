Detailed Description

The core employee: a named person who can be wrapped with decorators.

An Employee has no profession or competency on its own. These are added by wrapping it in EmployeeProfession and EmployeeCompetency decorators.

Design patterns
  • Decorator (ConcreteComponent).
  • Template Method (ConcreteClass): supplies the base prepare, perform and finish steps.
  • Prototype (ConcretePrototype): clone() copies the employee.
