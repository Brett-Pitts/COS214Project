Detailed Description

Abstract base of every employee and every employee decorator.

Defines the interface the rest of the system sees. It also implements the links that let employees take part in a team: a successor (the next employee in the chain) and a mediator (the team). Neither is owned.

Design patterns
  • Decorator (Component): Employee and Manager are the concrete components, EmployeeDetail is the decorator.
  • Chain of Responsibility (Handler): handleWork() passes a work unit to the successor when this employee cannot advance it.
  • Template Method (AbstractClass): doWork() runs prepare, perform and finish.
  • Mediator (Colleague): receive() gets messages from the team.
  • Prototype (Prototype): clone() copies an employee.
See also
Employee, EmployeeDetail

◆ canAdvance()

bool EmployeeComponent::canAdvance ( WorkUnit *  workUnit)
private

Checks whether this employee may advance a work unit from its current state.

The level needed depends on the state of the unit: Ready needs at least Intern, Ongoing at least Junior and Escalated at least Senior (see EmployeeCompetency). In any other state the answer is false. Only the level is checked here; the profession is matched by the Team.

Parameters
workUnitThe unit to check.
Returns
true if compareCompetency() accepts the level needed for the unit's state.

◆ doWork()

void EmployeeComponent::doWork ( WorkUnit *  workUnit)
virtual

Does the work on a unit by running prepare(), perform() and finish() in that order.

All three steps are run on every call, whatever the state of the unit. Then the mediator (if set) is told, so the rest of the team receives a message that this employee worked on the unit. A null unit is ignored. This does not change the state of the unit; handleWork() does that afterwards.

Parameters
workUnitThe unit being worked on.

◆ handleWork()

bool EmployeeComponent::handleWork ( WorkUnit *  workUnit)

Handles a work unit, or passes it along the chain.

If this employee can advance the unit (canAdvance()), it does the work with doWork() and then calls WorkUnit::advanceState(), which moves the unit on by one state. Otherwise the unit is passed to the successor. If there is no successor, a message that nobody in the chain can handle the unit is printed.

Parameters
workUnitThe unit to handle. A null unit is not handled.
Returns
true if this employee or a later one in the chain did the work.
