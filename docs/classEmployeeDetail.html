Detailed Description

Abstract decorator that adds a detail (profession or competency) to an employee.

Holds the component it wraps, takes ownership of it and deletes it in the destructor. The name, core, profession and competency queries, setMediator() and doWork() are passed on to the wrapped component, so concrete decorators only add their own part.

Design patterns
  • Decorator (Decorator).
  • Template Method: doWork() runs this decorator's prepare() and perform(), then the wrapped component's doWork(), then this decorator's finish(). The versions of prepare(), perform() and finish() in this class do nothing; concrete decorators override them.
