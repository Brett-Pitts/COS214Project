Detailed Description

Concrete state: nobody could do the work and no retries are left.

Team::assignWork() sets this state when no member can advance a work unit and the retry limit has been reached. Before that, the unit is sent back to Ready with WorkNode::reset(). handle() does nothing, so a failed node stays failed.

Design pattern
State (ConcreteState); the context is WorkNode.
