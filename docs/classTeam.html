Detailed Description

A group of employees of one profession; the leaf of the company tree.

Work is given to the team with assignWork(). The first member is asked to handle the unit; a member who cannot advance it in its current state passes it to the next member (the chain is linked in addMember()). The team is also the mediator of its members and tells them when someone has worked on a unit.

Design patterns
  • Composite (Leaf): a Team has no child nodes, so add(), remove() and getChild() do nothing.
  • Mediator (ConcreteMediator): members are the colleagues.
  • Chain of Responsibility: members are linked through setSuccessor() in addMember().
See also
CompanyNode, Mediator, EmployeeComponent

◆ addMember()

bool Team::addMember ( EmployeeComponent *  employeeComponent)

Adds an employee to the end of the team.

The employee is rejected if it is null, or if the team has a profession and the employee does not have it (checked with compareProfession(), through the decorators). Otherwise the previous last member's successor is set to the new employee, the new employee's mediator is set to this team, and the employee is appended. The chain and the mediator are therefore set up in one place.

Parameters
employeeComponentThe employee to add. The team takes ownership only if the employee is accepted.
Returns
true if the employee was added, false if it was rejected.

◆ assignWork()

void Team::assignWork ( WorkUnit *  workUnit)

Gives a work unit to the team and lets the members work on it as far as they can.

Does nothing if the team has no members or the unit is null. If the unit requires a profession, nothing happens unless that profession is registered (see EmployeeProfession::hasProfession()) and, for a team that has a profession, equal to the team's own.

Then the first member's handleWork() is called again and again for as long as it returns true. Each call moves the unit on by one state, so one call of assignWork() can carry a unit through several states (for example from Ready to Completed) if the members have a high enough level.

If no member could advance the unit at all and it is Ready, Ongoing or Escalated, one retry is used with WorkNode::reset(), which sends the unit back to Ready. When no retries are left, the unit is set to Failed instead.

Parameters
workUnitThe unit to assign.
