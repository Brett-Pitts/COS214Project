Detailed Description

Concrete state: the work node waits for other work to be completed first.

Every new node starts here. When a prerequisite completes, WorkNode::update() removes it from the node's list and advances the node once the list is empty.

Design pattern
State (ConcreteState); the context is WorkNode.
