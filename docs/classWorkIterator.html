Detailed Description

Walks a work tree depth first and stops on work units that are Ready.

Parents are visited before their children and children in the order they were added. Only WorkUnit objects in the Ready state are returned; projects and units in any other state are skipped. The iterator only keeps the starting node and the current node, and moves with getChild() and getParent().

A new iterator is not on any item yet: call first() before currentItem().

Design pattern
Iterator (ConcreteIterator); the aggregate is WorkNode.
