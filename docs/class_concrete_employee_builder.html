Detailed Description

Builds an employee by wrapping it in profession and competency decorators.

Parts are added from the outside in: the first part that is added becomes the outermost decorator, each later part is placed inside the earlier ones, and finish() puts the Employee or Manager core in the middle.

Design pattern
Builder (ConcreteBuilder). The product is an EmployeeComponent made of an Employee or Manager core wrapped by EmployeeProfession and EmployeeCompetency decorators.
See also
EmployeeBuilder, EmployeeDirector, EmployeeProfession, EmployeeCompetency
