Detailed Description

Decorator that gives an employee a profession (for example coder or plumber).

Professions are kept by name in a static registry, so a new industry needs no new class. The constructor adds the name to the registry if it is not there yet.

Design patterns
  • Decorator (ConcreteDecorator).
  • Template Method (ConcreteClass): adds its part to prepare, perform and finish.
  • Prototype (ConcretePrototype): clone() copies the decorator chain.
See also
EmployeeDetail, EmployeeCompetency
