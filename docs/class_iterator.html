Detailed Description

Abstract iterator over work nodes.

Lets clients walk a work tree (for example to find the next ready work unit) without knowing how the tree is stored.

Design pattern
Iterator (Iterator). WorkIterator is the concrete iterator. TeamIterator uses the same first, next, isDone and currentItem operations but does not derive from this class, because it returns Team objects rather than work nodes.
See also
Aggregate, WorkIterator, TeamIterator
