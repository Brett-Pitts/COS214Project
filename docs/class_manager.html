Detailed Description

An employee with two extra operations: handling escalations and cancelling projects.

A Manager takes part in the chain of responsibility like any other employee, in the position in which it was added to the team.

Design patterns
  • Decorator (ConcreteComponent), as a subclass of Employee.
  • Chain of Responsibility (ConcreteHandler): handles work like any other member.
  • Prototype (ConcretePrototype): clone() copies the manager.
