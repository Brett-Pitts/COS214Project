Detailed Description

A project or phase: a work node that contains other work nodes.

A project holds sub-projects and work units. It is completed when all of its children are completed: the last child to complete puts the project in Escalated and advances it (see Escalated::handle()), and that in turn can complete the project's own parent. Phases of a larger project are simply Projects as well.

Design patterns
  • Composite (Composite): children are WorkNode pointers.
  • Prototype (ConcretePrototype): clone() copies the project and its children.
  • Iterator (ConcreteAggregate): createIterator() is inherited from WorkNode.
See also
WorkNode, WorkUnit

◆ add()

void Project::add ( WorkNode * workNode)
virtual

Adds a child to the end of the project.

A null pointer is ignored. If this project (or anything below it) already has a node with the child's name, "1" is added to the end of the child's name once; the new name is not checked again. The child's parent is set to this project. The child's mediator is not set.

Parameters
workNodeThe sub-project or work unit to add. Ownership passes to this project.

Implements WorkNode.
