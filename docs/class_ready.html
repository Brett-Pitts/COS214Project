Detailed Description

Concrete state: all prerequisites are done and the work can be picked up.

A work unit in this state can be advanced by an employee with at least Intern competency (see EmployeeComponent::canAdvance()). WorkIterator only stops on work units in this state.

Design pattern
State (ConcreteState); the context is WorkNode.
