Detailed Description

Abstract state of a work node.

Each concrete state decides what happens when the node is advanced and which state comes next.

Design pattern
State (State). The concrete states are WaitingForPrerequisites, Ready, Ongoing, Escalated, Completed, Failed and Cancelled. The context is WorkNode.
