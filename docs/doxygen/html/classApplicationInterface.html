Detailed Description

Facade over the TIVIDY engine: owns the company and workflow trees.

Presents one simple interface for building a company, building projects, running the demo scenarios and saving or restoring state.

Design patterns
  • Facade: the one entry point for the interface.
  • Memento (Originator): creates and restores Memento objects that hold a copy of the company or the workflow. FileSystem is the caretaker.
See also
Memento, FileSystem, WorkNode, CompanyNode
