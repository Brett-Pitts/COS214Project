Detailed Description

Concrete state: the work node was cancelled and will not run.

Manager::cancelProject() sets this state on the project it is given. This is an end state and handle() does nothing. Escalated::handle() does not complete a parent that is Cancelled.

Design pattern
State (ConcreteState); the context is WorkNode.
