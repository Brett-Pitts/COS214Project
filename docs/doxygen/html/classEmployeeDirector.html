Detailed Description

Runs the build steps in the right order to create employees of a given level.

Design pattern
Builder (Director). It uses an EmployeeBuilder, so the same steps can build different representations.
See also
EmployeeBuilder, ConcreteEmployeeBuilder

◆ build()

EmployeeComponent * EmployeeDirector::build ( std::string  name,
std::string  profession,
std::string  competency 
)
private

Runs reset, addProfession, addCompetency and finish on the builder.

The results of addProfession() and addCompetency() are not checked, so the function does not return nullptr: if the competency name is not recognised, the employee is built without a competency decorator. The employee is never a Manager.

Parameters
nameName of the employee.
professionName of the profession.
competencyName of the competency level, passed to the builder as it is.
Returns
The finished employee. The caller owns it.

EmployeeComponent * EmployeeDirector::makeIntern ( std::string  name,
std::string  profession 
)

Builds an employee with the competency "intern" (see build()).

Warning
The level is passed to the builder in lower case. EmployeeCompetency only recognises "Intern", "Junior" and "Senior" (case-sensitive), so ConcreteEmployeeBuilder rejects it and the employee is built with a profession but without a competency. Such an employee cannot advance any work unit.
Parameters
nameName of the employee.
professionName of the profession.
Returns
The new employee. The caller owns it.
