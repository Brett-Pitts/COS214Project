Detailed Description

Concrete state: the work needs a senior employee to finish it.

Escalated does not mean the work failed. It is also entered when QA finds bugs or an inspection fails, so the unit is redone at senior level.

Design pattern
State (ConcreteState); the context is WorkNode.
