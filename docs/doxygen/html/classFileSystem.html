Detailed Description

Stores mementos by name and saves them to, or loads them from, files.

Design pattern
Memento (Caretaker). It keeps mementos without looking inside them, except when writing them to a file (it is a friend of the employee classes for that reason).
See also
Memento, ApplicationInterface
