Detailed Description

A single piece of work that one profession can do; the leaf of the work tree.

A work unit needs exactly one profession, and its retry limit is fixed at 3. It starts in WaitingForPrerequisites and then moves through Ready, Ongoing, Escalated and Completed as employees work on it.

Design patterns
  • Composite (Leaf): cannot have children, so add() does nothing.
  • Prototype (ConcretePrototype): clone() copies the unit.
